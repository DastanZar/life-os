Fixing inflection/energy mismatch with ElevenLabs — every solution, mapped

Grounded in the real pipeline: teardown measured r=0.06 contour correlation, 17 dB vs 32 dB energy range, +70 Hz register offset. Real file/line refs from train_second.py / models.py.

1 · Master decision map — where each solution lives

2 · B1 — EL-oracle F0/energy distillation (the answer-key fix)

KEY FACT The fork already trains an F0 loss — loss_F0_rec = smooth_L1(F0_real, F0_fake)/10 (train_second.py:699), added as λ_F0·loss_F0_rec to the generator loss (:770). But its teacher is JDCNet on our own mel — blurry, frame-level, word-blind. B1 swaps the blurry teacher for EL's real contours, aligned per word. Same trick that fixed duration.

3 · C1 — re-wake the StyleEncoder (per-sentence improvisation)

KEY FACT The module already exists in the codebase — StyleEncoder (models.py:200), instantiated as model.style_encoder + model.predictor_encoder (:800–803), and the trainer feeds it a reference mel every batch (s = model.style_encoder(st), :681–684). Kokoro's inference path just bypasses it with frozen voicepack rows. C1 = stop bypassing.

4 · The rest, briefly

A1 · speed dial Durations run ~15% long; every pitch gesture is time-dilated flat. speed ≈ 1.1 at inference compresses the timeline back — gestures steepen. Free, instant, composes with everything. Don't exceed ~1.1 until punctuation pauses are boosted (they're already 200 ms/sent under-paused).
A2 · style bank Cluster EL audio by sentence function (question / confirmation / apology / amount-reading / greeting). For each cluster, compute a style row → extend the voicepack tensor with new rows. At synthesis, pick row by intent. Zero architecture change — the voicepack is just a table, we add pages. B2's emotion tags make cluster labels free.
B2 · emotion-tagged data Regenerate a variant set via EL: same sentences with [excited], [apologetic], [whispers] tags / varied stability. The tag IS the label. Feeds B1 (conditional melody) and A2 (clean clusters). Cost: EL credits only.
B3 · ΔF0 viewer Add per-word paired bars (EL peak position + swing vs model's) to the teardown card. Becomes the regression-test dashboard for B1: every retrain, check r and dB range here. Hours of work, pure JS/HTML.
C2 · intent embedding Small learned vector (question/complaint/confirmation…) injected into the predictor. Needs labels (B2), weaker than C1, but trains fast. Good middle step if C1's reference-clip UX is unwanted.
D1 · hybrid routing Voice-bot intents are finite: route greetings/apologies/objections (expressive-critical) to live EL API; run local Kokoro for bulk informational speech (amounts, dates, KYC lists). Latency/cost tradeoffs per intent class. No model work.
